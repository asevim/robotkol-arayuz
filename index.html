Model hizalama -

Açılar model açısıdır: 0 = dik poz (kol dimdik yukarı, üst kol konnektörün karşısında, bilek düz). Firmware pose komutunu biliyorsa açılar ve kalibrasyon firmware'den gelir (kcal); aşağıdaki ref/ters yalnızca eski firmware için. ref = kol dik pozdayken o eklemin encoder açısı; model = işaret × (açı − ref). Önizlemede kaydırıcılar model açısını verir (başlangıç: STEP pozu).
